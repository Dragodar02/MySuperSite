Sci-Fi Outpost

Real-time Environment in UE5

Опис проєкту

Повноцінна ігрова локація, створена на Unreal Engine 5. Основний фокус був на роботі з освітленням (Lumen) та створенні модульних асетів для побудови бази.

Деталі:

  • Використання Nanite для високої деталізації.
  • Налаштування динамічного освітлення та пост-процесингу.
  • Створення Material Master для гнучкого налаштування поверхонь.
