Про проєкт

BeatWave - це сучасний музичний стрімінговий сервіс. Головна ідея - надати користувачам безшовний досвід прослуховування музики з можливістю візуалізації звукових хвиль.

"Музика — це стенограма емоцій." - Цей проєкт створений з любов'ю до звуку.

Функціонал:

  • Розумний Плеєр:

    Підтримка черги відтворення, shuffle, repeat та gapless playback.

  • Аудіо Візуалізація:

    Використання Web Audio API для рендерингу частот у реальному часі на Canvas.

  • PWA Support:

    Можливість встановлення як додатка на мобільний телефон.

Під капотом:

Vue.js 3 Pinia State Web Audio API Node.js backend
