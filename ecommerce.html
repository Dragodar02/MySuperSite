E-Commerce Platform

Повнофункціональний інтернет-магазин

Про проєкт

ModernShop - це масштабована платформа електронної комерції, розроблена для забезпечення найкращого користувацького досвіду. Вона побудована на MERN стеку (MongoDB, Express, React, Node.js) і забезпечує швидке завантаження сторінок, безпечні платежі та зручне керування каталогом.

Метою проекту було створення універсального рішення для малого та середнього бізнесу, яке дозволяє запустити онлайн-магазин за лічені хвилини.

Основний функціонал:

Кошик та Checkout

Повністю функціональний кошик з збереженням стану та покроковим оформленням замовлення.

Адмін Панель

Дашборд для керування товарами, категоріями, замовленнями та користувачами.

Платежі

Інтеграція Stripe та PayPal для безпечної обробки транзакцій.

Відгуки

Система рейтингів та коментарів для кожного товару.

Технологічний стек:

  • React.js / Redux Toolkit
  • Node.js / Express
  • MongoDB / Mongoose
  • Tailwind CSS
  • Docker
  • AWS S3
